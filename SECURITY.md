# Security Policy

## Supported Versions

We actively support and fix security issues for the following versions of TaskManager:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do **NOT** open a public issue. Instead, report it privately to the maintainer:

- **Email**: roydibyajyoti@github.com

We will investigate the report and aim to respond within 48 hours to coordinate a security patch and release schedule.
