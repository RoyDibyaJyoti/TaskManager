# Application Screenshots

This directory is reserved for application screenshots displayed on the main project `README.md` page.

Please add the following screenshots to showcase the application:

1. `dashboard_light.png` - Showcase the Dashboard with metric cards and category/priority progress bars (Light Mode).
2. `tasks_list_dark.png` - Showcase the Tasks List View with search filtering and sorted items (Dark Mode).
3. `task_dialog_symmetrical.png` - Highlight the redesigned Add Task dialog with symmetrical layout grids and inline error validations.
4. `preferences_native.png` - Show the native macOS Preferences dialog displaying themes and settings.
5. `about_native.png` - Show the native macOS About dialog containing version and developer attributes.

---

## Technical Specifications
- **Format**: PNG or JPEG.
- **Resolution**: Min 1280x800 recommended for high-retina displays.
- **Frame**: Keep window shadows clean. Do not include desktop environment frames.
